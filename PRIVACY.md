# Privacy policy

_Last updated: 2026-11-15_

**This app collects nothing.**

- It does not collect, store, or share any personal data.
- It has no internet access, no analytics, no advertising and no crash reporting.
- It uses two Android permissions:
  - **Modify system settings** (`WRITE_SETTINGS`), to change the TV's screen timeout. It reads
    and changes only that one setting.
  - **Run at startup** (`RECEIVE_BOOT_COMPLETED`), to set the timeout again after the TV restarts.
- It keeps three values on the TV: the time you chose, whether to keep it set, and the TV's own
  timeout from before the app first changed it (so it can be restored). They are not included in
  Android's backup and are deleted when you uninstall the app.

If this changes, this file will be updated **before** the change is released, describing what is
collected, why, where it is stored, and how to delete it.

Questions: open an issue in this repository.
